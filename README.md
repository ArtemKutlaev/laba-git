# Проект

Это учебный проект для изучения Git и GitHub.

## Описание проекта

Проект создан в рамках лабораторной работы по Git и GitHub.

В нём демонстрируются работа с ветками, Issues, Pull Requests и разрешение конфликтов.

## Назначение

Проект демонстрирует базовые возможности GitHub и совместную работу с репозиторием.
